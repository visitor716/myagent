# save-codex-plan

## 用途

从 tmux pane、文件或 stdin 中提取最后一个真实 proposed_plan 块，保存到 Obsidian 和 tg-agent-gateway 项目计划目录。

## 运行方式

```bash
scripts/save-codex-plan/save-codex-plan --help
```
