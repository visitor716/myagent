# _windows_helpers.py

## 用途

Windows 脚本共用 helper 模块，提供 Windows 环境检查、管理员判断、命令运行、目录创建和复制移动工具函数。

## 运行方式

```bash
此文件是共享 Python 模块，通常由其他 Windows 脚本导入，不直接运行。
```
