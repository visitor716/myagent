# calibration_precision_tool.py

## 用途

读取 27x27 标定点实测坐标，按理论点位和阈值计算偏差、合格率和 NG 点，既可命令行运行也可启动桌面检查工具。

## 运行方式

```bash
python3 scripts/calibration_precision_tool/calibration_precision_tool.py --help
```
