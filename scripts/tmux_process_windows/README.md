# tmux_process_windows.sh

## 用途

查看和管理 tmux 会话、窗口、pane 及其进程，并支持打开新的 Windows 终端或发送/停止 pane 命令。

## 运行方式

```bash
bash scripts/tmux_process_windows/tmux_process_windows.sh summary
```
