# start-cc-connect-hidden.py

## 用途

在 Windows 上以隐藏窗口方式启动 cc-connect，并把输出写入指定日志。

## 运行方式

```bash
python3 scripts/apps/cc-connect/start-cc-connect-hidden/start-cc-connect-hidden.py --what-if
```
