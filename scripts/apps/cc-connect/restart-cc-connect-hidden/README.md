# restart-cc-connect-hidden.py

## 用途

停止正在运行的 cc-connect.exe 后调用隐藏启动脚本重新拉起 cc-connect。

## 运行方式

```bash
python3 scripts/apps/cc-connect/restart-cc-connect-hidden/restart-cc-connect-hidden.py --what-if
```
