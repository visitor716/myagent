# fix-md-notepadpp.py

## 用途

备份并写入 Windows 注册表，把 .md 文件关联到指定 Notepad++。

## 运行方式

```bash
python3 scripts/apps/windows-shell/fix-md-notepadpp/fix-md-notepadpp.py --help
```
