# 清理导航栏残留.py

## 用途

清理 Windows 文件资源管理器导航栏中的百度网盘、iCloud 等残留注册表项并重启 explorer。

## 运行方式

```bash
python3 scripts/apps/windows-shell/清理导航栏残留/清理导航栏残留.py --help
```
