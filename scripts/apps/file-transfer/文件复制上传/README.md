# 文件复制上传.py

## 用途

中文版本的 DR Laser 文件复制上传脚本，默认机台为 4144A。

## 运行方式

```bash
python3 scripts/apps/file-transfer/文件复制上传/文件复制上传.py --machine-number <机台编号>
```
