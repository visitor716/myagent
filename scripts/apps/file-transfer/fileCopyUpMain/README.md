# fileCopyUpMain.py

## 用途

汇总前一天 DR Laser 报警、CCD 报警和产能数据，按机台编号整理并上传到共享盘。

## 运行方式

```bash
python3 scripts/apps/file-transfer/fileCopyUpMain/fileCopyUpMain.py --machine-number <机台编号>
```
