# CreateTaskWithSchtasks.py

## 用途

用 schtasks 创建或覆盖一个每日执行的 Windows 计划任务，默认执行 task-action.py。

## 运行方式

```bash
python3 scripts/apps/task-scheduler/CreateTaskWithSchtasks/CreateTaskWithSchtasks.py --help
```
