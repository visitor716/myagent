# codex-chrome配置.py

## 用途

修改 Codex 配置中的 chrome-devtools MCP 配置块，并在写入前备份原 config.toml。

## 运行方式

```bash
python3 scripts/apps/codex/codex-chrome配置/codex-chrome配置.py --config ~/.codex/config.toml
```
