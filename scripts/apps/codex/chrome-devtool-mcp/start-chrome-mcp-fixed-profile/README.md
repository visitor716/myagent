# start-chrome-mcp-fixed-profile.py

## 用途

启动固定用户数据目录和 9222 调试端口的 Windows Chrome，供固定端口 MCP 模式连接。

## 运行方式

```bash
python3 scripts/apps/codex/chrome-devtool-mcp/start-chrome-mcp-fixed-profile/start-chrome-mcp-fixed-profile.py --help
```
