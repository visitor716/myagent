# codex-launcher.py

## 用途

交互式启动 Codex，并让用户选择 Chrome DevTools MCP 的自动连接或固定端口模式。

## 运行方式

```bash
python3 scripts/apps/codex/codex-launcher/codex-launcher.py --help
```
