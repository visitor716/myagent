# sync-chatgpt-project-docs.sh

## 用途

将 ChatGPT Project 相关文档合并成 bundle，并可通过 opencli browser 自动上传到指定 ChatGPT Project。

## 运行方式

```bash
bash scripts/sync-chatgpt-project-docs/sync-chatgpt-project-docs.sh --project-url <url> --dry-run
```
