# analyze-uncategorized.py

## 用途

读取 skills-download 中尚未分类的技能目录，提取 SKILL.md 的 YAML 元数据，并输出名称、描述和附加信息，便于人工判断归类。

## 运行方式

```bash
python3 scripts/analyze-uncategorized/analyze-uncategorized.py --help
```
